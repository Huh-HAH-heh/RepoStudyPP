# RepoStudyPP

Учебный проект на **C# и WPF XAML**, подготовленный для импорта в [XAML.io](https://xaml.io/).

## Открытие в XAML.io

1. Откройте репозиторий GitHub и нажмите **Code → Download ZIP**.
2. Перейдите на https://xaml.io/.
3. Выберите импорт исходного проекта (**Import Source**) и загрузите ZIP-архив.
4. XAML.io распознает WPF-проект и попробует запустить его в браузере через OpenSilver.

В проекте используется стандартная структура WPF: `App.xaml`, `MainWindow.xaml`, C# code-behind и один файл проекта.

## Обычный запуск в Visual Studio

Нужен .NET 10 SDK и компонент **.NET desktop development**.

Откройте `RepoStudyPP.csproj` в Visual Studio и запустите проект.

## Разделы

- Главная страница двух учебных работ.
- Список животных и поиск по кличке или номеру.
- Добавление животного.
- Заявки на взятие животного в семью или передачу в приют.
- Ветеринарный журнал.
- Отчёт для администратора.

## Примечание

Это учебная версия. Данные животных, заявок и ветеринарных записей хранятся в памяти приложения и сбрасываются после перезапуска.

XAML.io работает с WPF-подобным XAML через OpenSilver. Не все возможности WPF обязательно поддерживаются в браузерной среде; проект использует базовые элементы интерфейса и стандартные обработчики событий.
