# RepoStudyPP

Учебная практическая работа №4 «Создание интерфейса системы».

Программа для небольшого приюта животных. Интерфейс сделан на C# и XAML с обычными контейнерами компоновки: Grid, StackPanel, Border, ScrollViewer и UniformGrid.

## Что есть в программе

- Просмотр списка животных и карточки с данными.
- Поиск по кличке и номеру, фильтры по виду, полу и породе.
- Добавление животного сотрудником приюта. Указываются основные сведения, дата поступления и информация о фото.
- Вход и простая регистрация пользователя с выбором роли.
- Заявки клиента на передачу животного или взятие питомца в семью.
- Оформление выдачи животного администратором или волонтёром.
- Ветеринарный журнал.
- Небольшой отчёт для администратора.

## Тестовые учётные записи

| Роль | Логин | Пароль |
| --- | --- | --- |
| Администратор | Nerd | Nerd |
| Клиент | GOON | GOON |
| Волонтёр | WERDO | WERDO |
| Ветеринар | vet | vet |

После регистрации пользователь сразу входит в программу. Новые роли можно выбирать в форме регистрации, потому что это демонстрационная учебная версия.

## Запуск в XAML.io

1. Откройте репозиторий на GitHub и выберите **Code → Download ZIP**.
2. Перейдите на https://xaml.io/.
3. Нажмите **Import Source** и загрузите ZIP-архив.
4. XAML.io попробует открыть WPF-проект через OpenSilver.

## Обычный запуск

Нужны .NET 10 SDK и компонент **.NET desktop development** в Visual Studio. Откройте файл проекта RepoStudyPP.csproj и запустите.

Данные хранятся в списках в памяти, поэтому после закрытия программы они сбрасываются. Фото в этой версии записывается как имя файла или путь, само изображение не загружается.
