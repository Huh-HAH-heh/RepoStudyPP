# RepoStudyPP

Учебный проект на **ASP.NET Core Blazor Web App (.NET 10)**.

Обе части проекта открываются в браузере:
- главная страница учебных работ;
- приложение для учёта животных в приюте.

## Что установить

В Visual Studio Installer выберите рабочую нагрузку **ASP.NET and web development**. Также нужен .NET 10 SDK. Рабочая нагрузка .NET MAUI больше не требуется.

## Запуск

Из папки проекта:

```powershell
dotnet restore
dotnet run
```

В Visual Studio откройте файл `RepoStudyPP.csproj` и запустите профиль `http`. Локальный адрес: `http://localhost:5080`.

## Примечание

Это учебная версия. Данные животных, заявок и ветеринарных записей хранятся в памяти приложения и сбрасываются после перезапуска. Учётные записи и пароли демонстрационные и не предназначены для реального использования.
